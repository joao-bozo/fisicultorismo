# Fisiologia

Site editorial sobre a história do fisiculturismo, suas divisões e os maiores nomes de cada categoria.

## Executar

```bash
python3 -m http.server 4173
```

Acesse `http://localhost:4173`.

## Estrutura

- `index.html`: conteúdo e estrutura
- `styles.css`: identidade visual responsiva
- `script.js`: interação do acordeão de categorias
